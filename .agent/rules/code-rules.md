## Go
- Type Safety: Dont use `any` if possible.
- Use modern Go
  - `interface{}` -> `any`
- Logging: Use `slog`
- Fiber V3: the parameter name of c.Locals("<param_name>") must be snake case.

## TypeScript
- Type Safety: Don't use `any` if possible.
- Use Modern TypeScript
  - Use Temporal API to replace Date.
